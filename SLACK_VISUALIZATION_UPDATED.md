## 🎯 **주요 개선 사항**

### ✅ **1. 특이사항 없으면 공란 처리**
- ❌ **이전**: "관련 뉴스 없음", "특보 없음", "주요 지진 없음" 등 메시지 표시
- ✅ **현재**: 특이사항 없으면 항목 자체를 표시하지 않음
- **결과**: 훨씬 깔끔하고 읽기 쉬운 리포트

### ✅ **2. 지진 최소 강도 6.0**
- ❌ **이전**: 규모 4.5 이상 모든 지진 표시
- ✅ **현재**: 규모 6.0 이상만 표시
- **결과**: 더 중요한 지진 정보만 표시

### ✅ **3. 메시지 순서 변경**
- ❌ **이전**: 글로벌 요약 → 국가별 상세 → 대륙별 뉴스
- ✅ **현재**: 글로벌 요약 → 대륙별 뉴스 → 국가별 상세
- **결과**: 전체 맥락을 먼저 파악한 후 상세 정보 확인 가능

## 💡 **실제 사용 시나리오**

### **시나리오 1: 모든 국가 정상**
```
1️⃣ 글로벌 요약: "특별히 중요한 이슈 없음"
2️⃣ 대륙별 뉴스: 일반 뉴스만 표시
3️⃣-14️⃣ 국가별 리포트: 대부분 헤더만 표시 (특이사항 없음)
```
→ **빠르게 확인 후 작업 계속 가능**

### **시나리오 2: 특정 국가에 문제 발생**
```
1️⃣ 글로벌 요약: "터키 인터넷 장애, 이라크 시위" 강조
2️⃣ 대륙별 뉴스: 관련 대륙 뉴스 표시
3️⃣ 터키 리포트: 상세 정보 표시 (인터넷 장애, 날씨 특보 등)
4️⃣ 이라크 리포트: 상세 정보 표시 (시위 관련 뉴스)
5️⃣-14️⃣ 다른 국가: 헤더만 표시 (특이사항 없음)
```
→ **문제 국가만 자세히 확인 가능**
