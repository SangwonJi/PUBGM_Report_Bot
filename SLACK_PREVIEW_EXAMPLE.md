## 🎯 **핵심 정보 한눈에 보기**

### ✅ 정상 상태 예시
- 모든 국가: 정상
- 플랫폼: 모두 정상
- 신뢰도: 높음
→ **즉시 확인 가능, 추가 조치 불필요**

### ⚠️ 주의 필요 예시
- 일부 국가: 모순 발견
- 신뢰도: 보통
- 권장사항: 추가 확인 필요
→ **수동 확인 권장**

### 🔴 긴급 상황 예시
- 트래픽 영향도: 심각
- 플랫폼 일부 다운
- 여러 국가 이상 징후
→ **즉시 대응 필요**
